# K S Meghana — Portfolio

Live site: https://ksmeghana-hub.github.io/myportfolio/

React + Vite site, pre-rendered to static HTML at build time so it paints instantly and then hydrates.

- All profile facts live in `src/data.js` (keep in sync with the resume).
- Photo, resume and certificate images are in `public/`.
- Every push to `main` builds and publishes the site through `.github/workflows/deploy.yml`
  (repo Settings → Pages → Source: **GitHub Actions**).

```bash
npm install
npm run dev      # local development at http://localhost:5613
npm run build    # production site in dist/
```

## Resume

`public/K_S_Meghana_Resume.pdf` is generated by `scripts/build_resume.py` (one page, ATS-friendly; needs Python with `reportlab` and the Windows Calibri font):

```bash
python scripts/build_resume.py public/K_S_Meghana_Resume.pdf
```
